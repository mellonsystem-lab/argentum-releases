# Argentum — downloads

Public download files for the **Argentum** series by MELLON (https://www.mellongp.com/argentum/).
This repository only hosts release files; the source code is private.

| App | What it is |
|---|---|
| Argentum Convert | Convert images and videos in batches (macOS first; a browser version is on the Argentum page) |

Download from the **Releases** page, or through the Argentum page on mellongp.com.

**Test versions** (0.x) are free to try and may change. On a Mac that has not been notarised yet, open the
downloaded app with right-click → Open the first time. Each release lists the SHA-256 of its file so you can
check the download: `shasum -a 256 <file>`.
